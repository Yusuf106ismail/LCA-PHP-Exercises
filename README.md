# LCA PHP Exercises

## Description
This repository contains PHP scripts and exercises completed as part of the Web Development curriculum, focusing on PHP fundamentals, variable declarations, data types, scope, and server execution.

## Exercises Included
- **Exercise 01: PHP Fundamentals**
  - `intro.php`: Introduction to PHP syntax, dynamic HTML output, date formatting, and random number generation.
  - `variables.php`: Variable usage, data types, arithmetic operations, and string concatenation.
  - `scope.php`: Demonstration of global scope, local scope inside functions, static variables, and the `$GLOBALS` superglobal array.
